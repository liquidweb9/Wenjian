## Regression Testing Strategy

### For Each Phase 2 Milestone

**Before starting**:
1. Run full Phase 1 test suite → must pass (166 tests)
2. Run baseline evaluation → record metrics

**After implementation**:
1. Run full test suite (Phase 1 + Phase 2) → all must pass
2. Run baseline evaluation → compare to baseline
3. If regression detected (MAE increases >20%, accuracy drops >10%), investigate

**Acceptable changes**:
- Minor MAE fluctuations (±1-2 points) due to LLM non-determinism
- Improved metrics (lower MAE, higher accuracy) are always acceptable
- Changes to mock evaluators in M2.3 when integrating real LLM calls

**Unacceptable regressions**:
- VERIFIED false positive rate increases
- Routing invalid rate >0%
- Phase 1 tests break
