## 🎉 完成的工作

### 新增 API Endpoints

#### 1. Job Target API (`/api/v1/job-targets`)
**文件**: `app/api/v1/job_targets.py` (~300 LOC)

**Endpoints**:

1. **POST /api/v1/job-targets**
   - 创建新的 job target
   - 支持手动创建或从模板创建
   - 包含 requirements 列表
   - 返回完整的 job target + requirements

2. **GET /api/v1/job-targets/{id}**
   - 获取指定 job target
   - 包含所有 requirements
   - 404 if not found

3. **GET /api/v1/job-targets**
   - 列出所有 job targets
   - 可选 `level` 参数过滤（intern/junior/mid/senior/staff）

4. **POST /api/v1/job-targets/{id}/parse-jd**
   - 解析 JD 文本，提取结构化 requirements
   - 使用 LLM（JDParser）
   - 返回 parsed requirements（不保存，用户可编辑后再保存）
   - 用于辅助用户创建 job target

**请求/响应模型**:
```python
class JobTargetCreate(BaseModel):
    title: str
    level: str  # intern|junior|mid|senior|staff
    interview_round: str  # resume|project|technical|system_design
    description: str | None
    source: str  # template|pasted_jd|manual
    raw_jd: str | None
    requirements: list[RequirementCreate]

class RequirementCreate(BaseModel):
    competency_code: str
    title: str
    description: str | None
    importance: float  # 0.0-1.0
    expected_level: int  # 1-5
    evidence_expectation: list[str]  # min 2 items

class JobTargetResponse(BaseModel):
    job_target_id: str
    title: str
    level: str
    interview_round: str
    description: str | None
    source: str
    raw_jd: str | None
    requirements: list[RequirementResponse]
    created_at: str
```

#### 2. Claim Gap Analysis API (`/api/v1/claim-gap`)
**文件**: `app/api/v1/claim_gap.py` (~250 LOC)

**Endpoints**:

1. **POST /api/v1/claim-gap**
   - 分析 resume 和 job target 之间的 gap
   - 输入：`resume_id`, `job_target_id`
   - 返回：gaps, coverage stats, interview plan

2. **GET /api/v1/claim-gap/resume/{resume_id}/job-target/{job_target_id}**
   - 获取 claim gap 分析（与 POST 相同，但支持 GET 缓存）

**请求/响应模型**:
```python
class ClaimGapRequest(BaseModel):
    resume_id: str
    job_target_id: str

class ClaimGapResponse(BaseModel):
    resume_id: str
    job_target_id: str
    gaps: list[GapResponse]  # All identified gaps
    coverage_stats: CoverageStatsResponse
    interview_plan: dict  # InterviewPlan with targets
    high_priority_targets: list[str]

class GapResponse(BaseModel):
    gap_type: str  # UNCOVERED_REQUIREMENT, HIGH_PRIORITY_WEAK_EVIDENCE, etc.
    claim_id: str | None
    requirement_id: str | None
    competency_code: str
    priority: float  # 0.0-1.0
    reason_codes: list[str]
    explanation: str
    # Context fields
    claim_text: str | None
    requirement_title: str | None
    requirement_importance: float | None
    requirement_expected_level: int | None
    claim_coverage_level: int | None

class CoverageStatsResponse(BaseModel):
    total_requirements: int
    covered_requirements: int
    uncovered_requirements: int
    weak_evidence_count: int
    high_priority_gaps: int
    coverage_percentage: float  # 0.0-1.0
```

### 数据库查询

使用 SQLAlchemy 2.0 async：
```python
from sqlalchemy import select
from sqlalchemy.orm import selectinload

stmt = (
    select(JobTarget)
    .where(JobTarget.job_target_id == job_target_id)
    .options(selectinload(JobTarget.requirements))
)
result = await db.execute(stmt)
job_target = result.scalar_one_or_none()
```

### 错误处理

使用 FastAPI HTTPException：
```python
from fastapi import HTTPException, status

if not job_target:
    raise HTTPException(
        status_code=status.HTTP_404_NOT_FOUND,
        detail=f"Job target {job_target_id} not found",
    )
```
