### 2. AbilityAggregator (`app/abilities/aggregator.py`)

**Purpose**: Aggregate observations across interviews and calculate stability.

**Key Features**:
- **Stability Calculation**: Combines 4 factors (session count, form diversity, consistency, evidence strength)
- **Score Trend Detection**: IMPROVING/STABLE/DECLINING based on first-half vs second-half comparison
- **Transfer Assessment**: UNTESTED/PARTIAL/DEMONSTRATED based on counterfactual performance
- **Gap Identification**: 6 gap types (single session, limited forms, no transfer, incomplete evidence, insufficient depth, contradictions)

**API**:
```python
aggregator = AbilityAggregator()

profile = aggregator.aggregate_observations(observations=[...])
# Returns: {
#   "total_interviews": 3,
#   "total_questions": 12,
#   "forms_used": ["concept", "debugging", "counterfactual", ...],
#   "avg_score": 78.5,
#   "score_trend": "IMPROVING",
#   "stability": "HIGH",
#   "stability_factors": {
#     "session_count": 3,
#     "form_diversity": 5,
#     "score_consistency": 0.85,
#     "evidence_strength": 0.82,
#     "stability_score": 0.79
#   },
#   "transfer_status": "DEMONSTRATED",
#   "counterfactual_performance": 80.0,
#   "unresolved_gaps": []
# }
```

**Stability Formula**:
```
stability_score = 
  0.30 × session_factor +      # Multi-session requirement
  0.30 × form_factor +          # Multi-form verification
  0.25 × consistency_factor +   # Score variance < 10pts
  0.15 × evidence_factor        # Strong evidence (>0.8)

HIGH:   score >= 0.75
MEDIUM: score >= 0.45
LOW:    score <  0.45
```

### 3. AnswerDiffer (`app/abilities/answer_diff.py`)

**Purpose**: Detect differences between answer versions and distinguish new evidence from coaching repetition.

**Key Features**:
- **Tokenization**: Regex-based, handles Chinese/English mixed text
- **New Evidence Detection**: Numbers, technical keywords, substantial length increase
- **Coaching Repetition Detection**: Minimal change (<15%), filler phrases
- **Substantive Change**: New evidence OR significant rewrite (>20%)

**API**:
```python
differ = AnswerDiffer()

diff = differ.compute_diff(
    original_text="我使用Redis作为缓存",
    revised_text="我使用Redis作为缓存，QPS达到5000，延迟p99为20ms"
)
# Returns: {
#   "total_added": 8,
#   "total_removed": 0,
#   "change_ratio": 0.32,
#   "new_evidence": True,  # Numbers detected
#   "coaching_repetition": False,
#   "is_substantive_change": True,
#   "original_hash": "abc123...",
#   "revised_hash": "def456..."
# }
```

**AnswerVersionManager**:
```python
manager = AnswerVersionManager()

# Suggests switching question after 3 non-substantive retries
should_switch = manager.should_suggest_switch_question(
    version_count=3,
    last_diff={"is_substantive_change": False}
)
# Returns: True
```

## Architecture Patterns

### 1. Stability Calculation

**Multi-factor weighted scoring**:
```
Session Factor (30%):
  1 session  → 0.0
  2 sessions → 0.5
  3+ sessions → 1.0

Form Factor (30%):
  <2 forms → 0.0
  2 forms  → 0.5
  3 forms  → 0.75
  4+ forms → 1.0

Consistency Factor (25%):
  std_dev < 5pts  → 1.0
  std_dev < 10pts → 0.75
  std_dev < 15pts → 0.5
  else → 0.25

Evidence Factor (15%):
  avg >= 0.8 → 1.0
  avg >= 0.6 → 0.75
  avg >= 0.4 → 0.5
  else → 0.25
```

### 2. Answer Diff Strategy

**Three-level classification**:
1. **New Evidence** (highest priority):
   - New numbers/metrics
   - 2+ technical keywords
   - >30% length increase

2. **Coaching Repetition** (reject):
   - <15% change ratio
   - 3+ filler phrases, <20 total additions

3. **Substantive Change** (accept):
   - New evidence OR >20% rewrite
   - NOT coaching repetition

### 3. Training Task Generation

**Gap-driven task selection**:
```python
gaps = profile["unresolved_gaps"]  # From aggregator

if "UNRESOLVED_CONTRADICTIONS" in gaps:
    create_contradiction_task(priority=0.95)
    
if "INCOMPLETE_EVIDENCE" in gaps or status != "VERIFIED":
    create_evidence_task(priority=0.9)
    
if avg_score < 60:
    create_concept_review_task(priority=0.85)
    
if "INSUFFICIENT_DEPTH" in gaps or avg_score < 70:
    create_depth_task(priority=0.8)
    
if "NO_TRANSFER_TESTING" in gaps:
    create_transfer_task(priority=0.75)
    
if "LIMITED_FORM_DIVERSITY" in gaps:
    create_form_diversity_task(priority=0.7)
```

**Current**: Aggregation logic exists but not automatically triggered  
**Limitation**: Profiles not updated when new interviews complete

**Current**: Tasks generated but no completion workflow

**Limitation**: Can't compare candidate A vs candidate B
