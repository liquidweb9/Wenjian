## 快速启动指南

### 1. 注册路由

在 `frontend-react/src/app/router.tsx` 添加：

```tsx
{
  path: '/job-targets',
  element: lazy(() => import('@/features/job-targets/pages/JobTargetListPage')),
},
// ... 其他路由
```

### 2. 添加Query Keys

在 `frontend-react/src/lib/query-keys.ts` 添加：

```tsx
jobTargets: {
  all: ['job-targets'] as const,
  lists: () => [...queryKeys.jobTargets.all, 'list'] as const,
  list: (filters: Record<string, any>) => [...queryKeys.jobTargets.lists(), filters] as const,
  details: () => [...queryKeys.jobTargets.all, 'detail'] as const,
  detail: (id: string) => [...queryKeys.jobTargets.details(), id] as const,
},
```

### 3. 启动开发服务器

```bash
cd frontend-react
pnpm dev
```

访问 `http://localhost:5174/job-targets`
