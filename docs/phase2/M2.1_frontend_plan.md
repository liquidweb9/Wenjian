### 2. Job Target 创建页面
**路由**: `/job-targets/new`  
**文件**: `frontend-react/src/features/job-targets/pages/JobTargetCreatePage.tsx`

**功能**:
- **Step 1**: 选择创建方式
  - 从模板创建（显示6个预定义模板）
  - 粘贴JD文本
  - 手动创建

- **Step 2**: 编辑基本信息
  - Title（必填）
  - Level（下拉选择：intern/junior/mid/senior/staff）
  - Interview Round（下拉选择）
  - Description（可选）

- **Step 3**: 编辑Requirements
  - 如果选择"粘贴JD"，显示JD文本框 + "解析"按钮
  - 点击"解析"→ 调用`parseJD` API → 显示解析结果
  - Requirement列表（可添加/编辑/删除）
  - 每个Requirement包含：
    - Competency Code（下拉选择，从23个competency中选）
    - Title（文本输入）
    - Description（文本区域，可选）
    - Importance（滑块，0.0-1.0）
    - Expected Level（下拉，1-5）
    - Evidence Expectation（列表，至少2项）

- **Step 4**: 预览和保存
  - 显示完整的job target信息
  - "保存"按钮 → 调用create API → 跳转到列表页

**UI组件**:
```tsx
<JobTargetCreatePage>
  <Stepper activeStep={step}>
    <Step label="选择方式" />
    <Step label="基本信息" />
    <Step label="编辑Requirements" />
    <Step label="预览保存" />
  </Stepper>
  
  {step === 0 && <CreateMethodSelector onSelect={setMethod} />}
  {step === 1 && <BasicInfoForm data={formData} onChange={setFormData} />}
  {step === 2 && (
    <RequirementsEditor
      requirements={requirements}
      onAdd={addRequirement}
      onEdit={editRequirement}
      onDelete={deleteRequirement}
      jdText={jdText}
      onParseJD={handleParseJD}
    />
  )}
  {step === 3 && <JobTargetPreview data={formData} />}
  
  <ActionButtons>
    {step > 0 && <Button onClick={prevStep}>上一步</Button>}
    {step < 3 && <Button onClick={nextStep}>下一步</Button>}
    {step === 3 && <Button onClick={handleSave}>保存</Button>}
  </ActionButtons>
</JobTargetCreatePage>
```

**React Query Hooks**:
```tsx
const useParseJD = () => {
  return useMutation({
    mutationFn: (data: { jobTargetId: string; jdText: string }) =>
      jobTargetApi.parseJD(data.jobTargetId, { jd_text: data.jdText }),
  });
};

const useCreateJobTarget = () => {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: jobTargetApi.create,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['job-targets'] });
    },
  });
};
```

### 4. Claim Gap 可视化页面
**路由**: `/resumes/:resumeId/claim-gap/:jobTargetId`  
**文件**: `frontend-react/src/features/claim-gap/pages/ClaimGapPage.tsx`

**功能**:
- **顶部：Coverage统计**
  - 饼图或进度条：Covered / Uncovered / Weak Evidence
  - 数字统计：Total, Covered, Uncovered, Weak, High-Priority Gaps
  - Coverage Percentage（大号显示）

- **中部：Gap列表**
  - 按priority降序排列
  - Gap类型徽章（不同颜色）：
    - UNCOVERED_REQUIREMENT（红色）
    - HIGH_PRIORITY_WEAK_EVIDENCE（橙色）
    - WEAK_EVIDENCE_CLAIM（黄色）
    - SUPPORTED_CLAIM（绿色）
    - IRRELEVANT_CLAIM（灰色）
  - 每个Gap显示：
    - Gap Type徽章
    - Priority评分（进度条）
    - Explanation（主要文本）
    - Reason Codes（小标签）
    - Claim Text / Requirement Title（上下文）
    - Coverage Level vs Expected Level（如果适用）
  - 过滤器：按Gap Type过滤

- **底部：Interview Targets**
  - 标题："推荐面试验证点"
  - Target列表（按priority排序）
  - 每个Target显示：
    - Competency Code
    - Priority
    - Explanation
    - "启动面试"按钮 → 跳转到interview创建（传递targets）

**UI组件**:
```tsx
<ClaimGapPage>
  <PageHeader>
    <Title>Claim Gap 分析</Title>
    <Subtitle>简历 vs {jobTarget.title}</Subtitle>
  </PageHeader>
  
  <CoverageSection>
    <CoverageChart stats={coverageStats} />
    <CoverageStats stats={coverageStats} />
  </CoverageSection>
  
  <GapSection>
    <SectionHeader>
      <Title>识别的Gap</Title>
      <GapTypeFilter value={gapTypeFilter} onChange={setGapTypeFilter} />
    </SectionHeader>
    <GapList>
      {filteredGaps.map(gap => (
        <GapCard key={`${gap.gap_type}-${gap.claim_id || gap.requirement_id}`} gap={gap} />
      ))}
    </GapList>
  </GapSection>
  
  <InterviewTargetsSection>
    <SectionHeader>
      <Title>推荐面试验证点 ({interviewPlan.total_targets})</Title>
      <Button onClick={handleStartInterview}>启动面试</Button>
    </SectionHeader>
    <TargetList>
      {interviewPlan.targets.map(target => (
        <TargetCard key={target.claim_id || target.requirement_id} target={target} />
      ))}
    </TargetList>
  </InterviewTargetsSection>
</ClaimGapPage>
```

**React Query Hook**:
```tsx
const useClaimGap = (resumeId: string, jobTargetId: string) => {
  return useQuery({
    queryKey: ['claim-gap', resumeId, jobTargetId],
    queryFn: () => claimGapApi.get(resumeId, jobTargetId),
    enabled: !!resumeId && !!jobTargetId,
  });
};
```

export const queryKeys = {
  // ... existing keys
  
  jobTargets: {
    all: ['job-targets'] as const,
    lists: () => [...queryKeys.jobTargets.all, 'list'] as const,
    list: (filters: Record<string, any>) => [...queryKeys.jobTargets.lists(), filters] as const,
