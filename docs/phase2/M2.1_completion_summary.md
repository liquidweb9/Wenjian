**文件**: `app/planning/claim_mapper.py` (~350 LOC, 22 tests)

- **Claim → Requirement 映射**：基于 competency mapping + title boost
- **Mapping strength 评分**：1 keyword=0.6, 2=0.75, 3+=0.9
- 支持中英文混合匹配（case-insensitive）

**核心算法**: Rule-based keyword matching（快速、可预测、可测试）

#### 6. Claim Gap Analyzer ✅
**文件**: `app/planning/claim_gap_analyzer.py` (~430 LOC, 14 tests)

- **5 种 Gap 类型**：
  - `UNCOVERED_REQUIREMENT` - 岗位需求未覆盖
  - `HIGH_PRIORITY_WEAK_EVIDENCE` - 高优先级需求证据薄弱
  - `WEAK_EVIDENCE_CLAIM` - Claim 覆盖度不足
  - `SUPPORTED_CLAIM` - Claim 有良好证据
  - `IRRELEVANT_CLAIM` - Claim 与岗位无关

- **6 种 Reason Codes**：详细解释 gap 成因
- **优先级评分公式**：基于 importance, evidence_gap, relevance
- **Coverage 统计**：total/covered/uncovered, weak evidence count, high-priority gaps

#### 7. Interview Plan Builder ✅
**文件**: `app/planning/interview_plan_builder.py` (~200 LOC, 10 tests)

- **从 Gap 分析生成面试计划**
- 包含所有高优先级 gaps（priority >= 0.7）
- 包含所有弱证据 claims（需验证）
- 采样支持良好的 claims（2 个）
- 排除无关 claims
- 按优先级降序排序

**输出**: `InterviewPlan` 包含 targets、statistics、high_priority_count

## 完整示例：端到端工作流

```python
from app.job_target.jd_parser import JDParser, MockLLMGateway
from app.planning import (
    ClaimMapper,
    ClaimGapAnalyzer,
    InterviewPlanBuilder,
)

# 1. 解析 JD
jd_text = """
后端工程师 - 中级
要求：
- 精通 Redis 缓存架构设计
- 熟悉 Kafka 消息队列
- 了解 MySQL 数据库优化
"""

jd_parser = JDParser(llm=MockLLMGateway())
jd_result = await jd_parser.parse_jd(jd_text)

requirements = [
    {
        "requirement_id": f"req_{i}",
        "competency_code": req.competency_code,
        "title": req.title,
        "importance": req.importance,
        "expected_level": req.expected_level,
    }
    for i, req in enumerate(jd_result.requirements)
]

# 2. Map Resume Claims
resume_claims = [
    {"claim_id": "c1", "text": "负责 Redis 缓存方案设计"},
    {"claim_id": "c2", "text": "使用过 MySQL 数据库"},
]

mapper = ClaimMapper()
claim_mappings = [
    mapper.map_claim(
        claim_id=claim["claim_id"],
        claim_text=claim["text"],
        requirements=requirements,
    )
    for claim in resume_claims
]

# 3. Analyze Gaps
analyzer = ClaimGapAnalyzer()
gap_result = analyzer.analyze_gaps(claim_mappings, requirements)

print(f"Coverage: {gap_result.coverage_stats.coverage_percentage:.0%}")
print(f"Uncovered: {gap_result.coverage_stats.uncovered_requirements}")
print(f"Weak Evidence: {gap_result.coverage_stats.weak_evidence_count}")
print(f"High-Priority Gaps: {gap_result.coverage_stats.high_priority_gaps}")

# 4. Build Interview Plan
builder = InterviewPlanBuilder()
plan = builder.build_plan(gap_result)

print(f"\nInterview Plan: {plan.total_targets} targets")
for target in plan.targets[:5]:  # Top 5
    print(f"  [{target.gap_type}] Priority {target.priority:.2f}")
    print(f"    {target.explanation}")
    print(f"    Reasons: {', '.join(target.reason_codes)}")
```

**示例输出**:
```
Coverage: 67%
Uncovered: 1
Weak Evidence: 1
High-Priority Gaps: 1

Interview Plan: 3 targets
  [UNCOVERED_REQUIREMENT] Priority 0.77
    Job requires Kafka (importance 0.85), but no matching claim found
    Reasons: REQUIREMENT_UNCOVERED, HIGH_IMPORTANCE_GAP
  
  [WEAK_EVIDENCE_CLAIM] Priority 0.52
    Redis coverage L2, expected L3
    Reasons: CLAIM_WEAK_EVIDENCE, LOW_COVERAGE_LEVEL
  
  [WEAK_EVIDENCE_CLAIM] Priority 0.45
    MySQL coverage L1, expected L3
    Reasons: CLAIM_WEAK_EVIDENCE, LOW_COVERAGE_LEVEL
```
